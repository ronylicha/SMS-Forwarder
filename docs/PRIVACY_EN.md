# Privacy Policy — SMS Forwarder

🇫🇷 [Français](PRIVACY.md) | 🇬🇧 English

*Last updated: March 4, 2026*

## Introduction

SMS Forwarder is an Android application developed by **QrCommunication**. This privacy policy describes how the application handles your data.

## Data collection

**SMS Forwarder does not collect any personal data.**

The application does not transmit any information to an external server, a third-party service, or the developer. There is no analytics, tracking, telemetry or advertising system built into the application.

## Data storage

All data generated by the application is stored **exclusively on your device**:

| Data | Storage | Description |
|--------|----------|-------------|
| History of forwarded SMS | Room database (local SQLite) | Sender, content, forwarding status, date |
| Filtering rules | Room database (local SQLite) | Numbers and keywords in whitelist/blacklist |
| Preferences | SharedPreferences (local) | Destination number, service state, display preferences |

This data never leaves your device, unless you explicitly use the CSV export feature.

## SMS transit

SMS forwarded by the application transit **exclusively via your mobile carrier's network**. The application uses Android's standard APIs to send SMS. No intermediate server is involved in the forwarding process.

## Permissions used

The application requires the following permissions, each strictly necessary for its operation:

| Permission | Justification |
|------------|---------------|
| `RECEIVE_SMS` | Intercept incoming SMS to trigger automatic forwarding |
| `SEND_SMS` | Send forwarded SMS to the configured destination number |
| `READ_PHONE_STATE` | Read the local SIM card number for anti-loop protection and multi-SIM support |
| `RECEIVE_BOOT_COMPLETED` | Automatically restart the forwarding service after a device reboot |
| `FOREGROUND_SERVICE` | Keep the forwarding service reliably active in the background |
| `FOREGROUND_SERVICE_SPECIAL_USE` | Declare the background service type, required since Android 14 |
| `POST_NOTIFICATIONS` | Display the service persistent notification and forwarding alerts, required since Android 13 |

No permission is used for data collection or profiling purposes.

## Security

- **Anti-loop protection**: the application automatically detects the local SIM card number to prevent infinite forwarding loops (an SMS forwarded to your own number would be re-intercepted indefinitely)
- **No secrets in source code**: the application's signing configuration uses environment variables
- **No network connection**: the application does not establish any internet connection. Only the carrier's SMS network is used

## Data deletion

You can delete all application data at any time:
- From the application: by clearing the history
- From Android settings: Settings > Apps > SMS Forwarder > Storage > Clear data
- By uninstalling the application: all data is automatically deleted

## Changes to this policy

Any change to this privacy policy will be documented in the application's CHANGELOG and updated in this document.
